1. Introduction

1.1 Software Overview

TS_Predictor is a professional tool for GNSS time series analysis and prediction. The software integrates five core modules: data processing, preprocessing, signal decomposition, nonlinear modeling and prediction, and model evaluation, providing users with an all-in-one solution from data input to result analysis.

TS_Predictor supports multiple mainstream GNSS data formats and offers flexible algorithm selection and parameter configuration. It is suitable for time series analysis tasks in fields such as crustal deformation monitoring and meteorological prediction.

1.2 Main Functions

  • Multi-source Data Support: Compatible with mainstream GNSS time series data formats including PBO, NGL, and CEA.
  • Data Quality Control: Integrates missing value imputation, outlier detection, step error correction, and Common-Mode Error (CME) extraction.
  • Adaptive Signal Decomposition: Provides various empirical mode decomposition and variational mode decomposition algorithms to separate different components in the signal.
  • Nonlinear Predictive Modeling: Supports a variety of machine learning and deep learning algorithms, and enables networked prediction combined with spatial information.
  • Comprehensive Model Evaluation: Automatically calculates multiple evaluation metrics and generates visual evaluation reports.

2. Software Environment and Installation

  • Operating System: Windows 10/11, Linux (Ubuntu 20.04 or later), macOS (11 or later)
  • Hardware Requirements: At least 8GB RAM is recommended. For deep learning model training, hardware with an NVIDIA GPU is recommended.

3. Data Module

3.1 Function Description

This module is responsible for importing raw GNSS time series data, standardizing formats, and preliminary visualization, providing a unified data foundation for subsequent analysis.

3.2 Operation Guide

Data Import

  • Operation: On the main interface of the software, click the Input File button.
  • Supported Formats: In the pop-up file selection dialog, select local files in PBO, NGL, or CEA format.

Format Standardization and Visualization

  • Automatic Processing: The software automatically recognizes the source data format and converts it into a unified internal standardized structure.
  • Visualization: After successful data loading, the main plotting area automatically generates a time series trend chart.

Data Output

  • Operation: Click the Save Standardized Data button.
  • Output Format: Data will be saved as a CSV (Comma-Separated Values) file. You can customize the save path and filename in the pop-up dialog.

4. Preprocessing Module (Optional)

4.1 Function Description

This module performs quality control on standardized data, including filling data gaps, detecting and correcting outliers, correcting step errors, and extracting Common-Mode Errors (CME). It aims to improve data quality and provide more reliable input for subsequent modeling.

4.2 Operation Guide

Activate the Module

  • On the main interface, check the option Run gCMEbox Preprocessing. The parameter panel on the right will expand to show preprocessing configuration items.
  • Note: gCMEbox is a MATLAB toolbox for extracting and analyzing common-mode errors from GNSS time series. The core algorithm is detailed in: Zhang, S., et al. (2025). gCMEbox: A MATLAB toolbox for extracting and analyzing common-mode errors from GNSS time series. Advances in Space Research, 75(1), 497–514. The toolbox code has been integrated into this software. The original project URL: https://github.com/lj-lijun/GNSS_time_series_CME_software

Parameter Configuration and Execution

  1. Missing Value Imputation (KKF): The software uses the Kriging-Kalman Filter (KKF) algorithm to impute missing data in the time series.
  2. Outlier Detection (IQR): Automatically identifies and marks outliers based on the Interquartile Range (IQR) criterion. Marked outliers are replaced with reasonable interpolated values. You can click View Outlier Report to check detailed locations after processing.
  3. Step Error Correction: The system automatically detects and corrects step errors caused by instrument changes, earthquakes, and other events.
  4. Common-Mode Error Extraction (CME): The software applies the algorithm in gCMEbox to extract common-mode errors from multi-station data and removes them from the original signal to enhance regional characteristic signals.

Data Output

  • After preprocessing, click Save Preprocessed Data. Data will be saved in CSV format; you can customize the save path.

5. Decomposition Module (Optional)

5.1 Function Description

This module provides a variety of adaptive signal decomposition algorithms to decompose complex GNSS time series into components of different frequencies (e.g., trend, periodic, noise components). It can selectively filter high-frequency noise to simplify subsequent modeling and analysis.

5.2 Operation Guide

Activate the Module

  • On the main interface, check Enable Decomposition Module to enter the algorithm selection and parameter configuration interface.

Select Decomposition Algorithm and Configure Parameters

Noise Reduction

  • Check the option Denoise: Remove the first IMF component. The software automatically identifies and removes the first Intrinsic Mode Function representing the highest-frequency noise, retaining other valid low- and mid-frequency components.

Data Output

  • Click Export Decomposition Results. Each decomposed component (IMF) is saved as a separate CSV file, with the filename containing the algorithm name and component index.

6. Nonlinear Modeling and Prediction Module

6.1 Function Description

This is the core module of the software. It provides various machine learning and deep learning algorithms and supports enhancing prediction performance using station spatial information. Users can build GNSS time series prediction models suitable for different complexities through flexible parameter configuration.

6.2 Operation Guide

Spatial Network Estimation (Optional)

  • When processing multi-station data, check Enable Spatial Network Prediction Model. The software constructs a spatial weight matrix based on the geographic coordinates of stations and integrates spatial correlation information into the prediction model to improve accuracy.

Select Algorithm and Configure Parameters

In Model Type, select Machine Learning or Deep Learning, then choose a specific algorithm from the submenu. The parameter table below loads configurable items for the corresponding algorithm.

Machine Learning Algorithms (SVM, RBF, ELM)

Parameter Description & Recommendations
Training/Testing Split Default 0.7. Recommended range: 0.7–0.9.
Window Size Default 15. Historical time steps used for prediction; adjust according to data sampling rate.
Hidden Layer Nodes (ELM) Default 30. Recommended range: 30–100.
Expansion Coefficient (RBF) Default 1000. Affects the shape of radial basis functions.
Penalty Coefficient C (SVM) Default 4. Controls penalty for model errors.
Kernel Coefficient Gamma (SVM) Default 0.001. Affects the influence range of a single sample.

Deep Learning Algorithms (BP, LSTM, GRU)

Parameter Description & Recommendations
Training/Testing Split Default 0.7.
Learning Rate Default 0.01. Recommended range: 0.0001–0.01.
Epochs Default 50. Recommended range: 50–200.
Window Size Default 15. Recommended to match the main period of the data (daily, weekly, monthly).

Training and Prediction

  • After parameter configuration, click the Run button.
  • The software automatically loads preprocessed or decomposed data and trains the model according to the set parameters. During training, the status bar at the bottom of the interface shows the training progress.
  • After training completes, the software automatically uses the trained model to predict future data for the specified steps.

7. Evaluation Module

7.1 Function Description

This module starts automatically after model prediction. It comprehensively evaluates model performance using multiple quantitative indicators and generates standardized evaluation reports for result analysis and model comparison.

7.2 Operation Guide

Automatic Evaluation

After prediction, the evaluation module runs automatically and calculates the following core metrics:

  • RMSE (Root Mean Squared Error): Measures the deviation between predicted and true values; sensitive to large errors. Smaller value = higher accuracy.
  • MAE (Mean Absolute Error): Measures the average magnitude of prediction error; robust to outliers. Smaller value = better performance.
  • sMAPE (Symmetric Mean Absolute Percentage Error): Dimensionless error metric for comparing model performance across datasets.
  • R² (Coefficient of Determination): Reflects the goodness of fit of the model to observations. Closer to 1 = stronger explanatory power.
  • WQE (Weighted Quality Evaluation): A comprehensive score calculated by weighting the above indicators, used for quick overall model assessment.

Result Output and Viewing

  • After evaluation, click Export Evaluation Report.
  • The report is saved as an Excel workbook (*.xlsx) in the Data/Results/ folder by default, including:
    • “Metrics” Worksheet: Values of all evaluation indicators listed above.
    • “Data” Worksheet: Original true values, model predicted values, and residual values.
    • “Charts” Worksheet: Visual results including predicted vs. true value curves and error distribution histograms.
